# Статус переработки dsh-pet на английский

Обновлено: 2026-11-22, 00:50 MSK. Ветка: `main`, HEAD `45a595f`.
База до переработки: `fb38ce6` (форк `PC2005-cloud/dsh-pet`, версия плагина 0.4.9).

## 0. Решение владельца от 2026-11-22: заморозка области

**В этой итерации закрываем только «видимую» волну** — то, что непосредственно видит
пользователь. Всё остальное отложено и выполняется отдельно, в других сессиях и только по
явному указанию владельца. Границы, критерии приёмки и условия возобновления — §2.1 и §7.

## 1. Назначение документов

| Файл | Что это |
|---|---|
| `STATUS.md` | этот файл: текущий статус, сделано/осталось, ближайшие шаги |
| `plan.md` | рабочий план: волны, пакеты, контракт субагента, матрица проверок, риски |
| `glossary.md` | обязательный глоссарий английских терминов |
| `baseline.md` | исторический снимок до начала работ (2026-11-21): гейты, окружение, ограничения |
| `strings-inventory.md` / `.json` | исторический инвентарь строк с китайским текстом |
| `../../HANDOFF.md` | передача контекста между сессиями, журнал батчей (раздел 14 — актуальный статус) |

Процессные документы написаны по-русски, потому что адресованы владельцу и будущим сессиям;
продуктовая и репозиторная поверхность при этом переводится на английский. Сканер
`check:english` ищет только CJK, поэтому кириллица в этих документах гейт не ломает.
Рабочие копии документов лежат в игнорируемом `.npm-cache/`; канон — в этом каталоге.

## 2. Правила исполнения

- Код, комментарии, тесты и продуктовую документацию правят только субагенты
  `opencode-go/deepseek-v4.1-flash`; координатор режет задачи, ведёт глоссарий, принимает
  диффы, гоняет гейты, коммитит.
- Один пакет = один коммит; параллельно не больше трёх субагентов; коммиты идут в `main`
  (решение владельца 2026-11-21), `origin/main` в актуальном состоянии.
- Действующие решения: D3 — карта английских подписей меню, имена файлов и ключи не
  переименовываем; D7 — протокольные маркеры истории не переводим; i18n-слой локалей
  настроек и чата не трогаем; персонаж сохраняется, переводится только язык; мемы-картинки
  и имена файлов не перерисовываем.

## 2.1. Область текущей итерации: «видимая» волна

**Входит в объём:**

- пользовательские строки runtime: подписи меню (английская карта уже есть), тексты пузырей,
  тостов и уведомлений, ошибки и валидация, которые всплывают в UI, состояния и подсказки
  чата/голоса/распознавания, погода и окружение, панель задач, карточка питомца, страница
  настроек, landing локального сервера, меню и трей рабочего стола, `--help` standalone,
  английский голос по умолчанию;
- тесты, которые сверяют эти видимые строки: только точечные обновления ожиданий; имена
  тестов и тестовые данные остаются на будущее;
- небольшая задача «видимого режима» сканера/фильтра, чтобы доказать чистоту видимой
  поверхности при непустом полном скане.

**Не входит (отложено до отдельного указания владельца):**

- комментарии и JSDoc (~12 829 находок), включая комментарии локалей и CJK-пунктуацию в `en.ts`;
- имена тестов и тестовые данные/фикстуры (~7 939 находок), кроме ожиданий изменённых
  видимых строк;
- документация: 9 документов, `openapi.yaml`, `site/`, `tools/`, переименование `prompts/`,
  корневые скрипты ассетов, `.github`, dotfiles, `_comment` в `package.json`
  (~4 818 находок + 3 имени файла);
- локали `zh.ts`/`ja.ts` и i18n-слой — по действующему решению не трогаем;
- контент: 27 мемов с китайским текстом внутри картинок, 114 имён анимаций, шрифт —
  не перерисовываем (D3);
- внутренние логи и диагностика: попадают в работу только если делят пакет с видимыми
  строками и это дёшево; иначе остаются на будущее;
- полный «ноль» `check:english` в `prepack`: при замороженной области недостижим, поэтому
  включается только в полной волне 6.

**Критерии приёмки видимой волны:**

1. Все перечисленные видимые строки — английские.
2. Полный `npm test` зелёный (ориентир 2754/598), `npm run build`, `prepack-check`,
   `check:runtime` — зелёные.
3. Отфильтрованная проверка видимой поверхности даёт ноль находок; полный сканер остаётся
   непустым, и это зафиксировано как ожидаемое состояние.
4. Скриншоты трёх поверхностей: страница настроек standalone, веб-оверлей, окно рабочего
   стола (если Electron доступен).
5. `STATUS.md` и `HANDOFF.md` обновлены, список отложенного зафиксирован.

## 6. Открытые вопросы

- Названия места и погоды приходят из сетевого IP-геокодинга и могут быть китайскими — это
  данные, не литералы; решить до волны 6 (оставить как данные / запросить английские названия
  у API / локализовать отображение).
- i18n: `lang="zh-CN"` на странице настроек остаётся до синхронизации с чат-панелью; формат
  времени в панели чата задаётся словарями локалей, а не кодом.
- Мемы-картинки и имена файлов остаются с китайскими именами (D3): это осознанное решение,
  `check:english` разрешает их через allowlist.
- `check:english` в `prepack` включается только в волне 6, чтобы не блокировать промежуточные
  сборки.

## 7. Условия возобновления отложенных волн

- Только по явному указанию владельца и только в отдельной сессии; автоматического
  продолжения нет.
- Начать с чтения `STATUS.md` (§0, §2.1, §7) и `HANDOFF.md` §15, затем `plan.md` §21.
- Каждая отложенная волна — отдельный трек: нарезка, гейты и коммиты по правилам из §2.
- Существующие артефакты (сканер `check:english`, allowlist, глоссарий, план, этот статус)
  переиспользуются; отложенные находки не удаляются и не «глушатся» в allowlist, чтобы
  будущий трек видел реальный объём.
