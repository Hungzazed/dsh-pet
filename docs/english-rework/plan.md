# План: полный перевод dsh-pet на английский, исполнение субагентами

Дата: 2026-11-21; обновлено 2026-11-22. Ветка: `main` (с 2026-11-21; `english-rework`
влит fast-forward). Коммит-база: `fb38ce6`.
Объём: весь репозиторий (код, комментарии, тесты, документация, инструментарий).
Метод: замена по месту, без второго языка и без слоя i18n.
Исполнение: только субагенты; координатор — планирование, проверки, коммиты.

## 1. Цель и критерий приёмки

Английский становится единственным языком репозитория и продукта: runtime-текст, промпты,
комментарии, названия тестов, документация, спецификация, страницы инструментария и правила
репозитория. Второго набора строк, переключателя языка и веток «если язык такой» не появляется.

Приёмка:
1. Все гейты зелёные (перечень в разделе 6).
2. Сканер `check:english` даёт ноль вхождений за пределами allowlist.
3. Число тестов и наборов не изменилось (2746 / 594), полный прогон зелёный.
4. Число тегов JSDoc в каждом файле не изменилось.
5. Сборка и `prepack-check` зелёные; `check:english` включён в `prepack`.
6. Три поверхности проверены глазами: веб-оверлей, независимый режим, окно рабочего стола
   (если Electron доступен).

## 2. Маршрут исполнения (закрыт 2026-11-21)

Требование владельца: реализация только субагентами `opencode-go/deepseek-v4.1-flash`.

Статус: маршрут проверен живым вызовом в свежей top-level сессии 2026-11-21:
`list_subagent_models()` показывает `opencode-go`, `list_subagent_models(provider="opencode-go")`
возвращает `deepseek-v4.1-flash`, пробный субагент ответил `OK`. Запись в
`~/.dsh/profiles/web/cordis.patch.yml` (`subagent-model-selection-settings.allowedModels`,
строки 130–134) на месте. Волна 0 исполнена этими субагентами (W0.1 — коммит `f4fba95`).

Оговорка: allowlist — событие политики, записываемое при создании сессии. Возобновлённая
старая сессия сохранит прежнюю политику; для работы маршрута нужна свежая top-level сессия.
Запасной маршрут `deepseek-official/deepseek-flash` не используется без явного согласия владельца.

- **Координатор (я):** нарезка задач, глоссарий, приёмка диффов, прогон гейтов, коммиты,

## 4. Контракт задачи для субагента

Шаблон, который получает каждый субагент (подставляются пакет, файлы, проверки):

```
Роль: перевод текста без изменения поведения.
Репозиторий: /home/developer/repo/dsh-pet, ветка english-rework.
Прочитай: .npm-cache/reports/plan-full-english.md (разделы 4-6) и
          .npm-cache/reports/glossary.md.

Пакет: <ID и название>.
Файлы (только эти): <список>.
Что делать: заменить китайский человеческий текст на английский — литералы, комментарии,
             JSDoc, названия тестов, markdown — в зависимости от типа пакета.
Не делать: не менять поведение, сигнатуры, имена идентификаторов, ключи конфига, пути,
           CSS-классы, протокольные маркеры, порядок импортов; не добавлять зависимости;
           не переформатировать файлы вне списка; не коммитить.
Правила текста: глоссарий обязателен; сохранять теги @param/@returns/@throws/@module и их
           пути; сохранять плейсхолдеры {target}, {n}; сохранять структуру markdown и ссылки;
           комментарий переводится по смыслу, а не пословно; код в примерах не меняется.
Если пакет меняет пользовательские строки — обнови тесты, которые их сверяют, в том же пакете.

Проверки (обязательны, вывод приложить):
  npx tsc --noEmit
  npx eslint <файлы пакета>
  npx prettier --check <файлы пакета>
  node --test <тестовые файлы пакета>        (если пакет меняет строки)
Вернуть: список файлов, число заменённых строк, решения по глоссарию, вывод проверок,
         `git diff --stat` по своим файлам, всё, что осталось спорным.
```

## 5. Глоссарий (фиксируется до первой задачи)

Канонические английские термины; отклонения запрещены.

- pet — питомец; не «animal», не «creature».
- whisper — короткая реплика по таймеру; не «murmur», не «chatter», не «mutter».
- bubble — облачко с текстом; не «popup», не «tooltip».
- balance — баланс/остаток средств; не «wallet», не «funds».
- work status — статус работы агента; не «job state».
- todo — задача в списке дел; не «task list item».
- sleep / wake — сон и пробуждение питомца.
- meme — картинка-реакция; не «sticker», не «emoji».
- animation — анимация; playback — воспроизведение; pose — поза.
- meme pack / animation pool — набор мемов, пул анимаций.
- host half / client half / standalone mode — половины плагина и независимый режим.
- settings page — страница настроек; config — конфигурация.
- memory — память; recall — выборка из памяти; provider — провайдер.
- voice — голос/озвучка; speech — синтез речи; hear — распознавание речи.
- session — сессия; turn — ход; tool call — вызов инструмента.
- desktop window — окно рабочего стола (не «desktop app»).

## 8. Правила нарезки и параллельности

- Пакеты не пересекаются по файлам; один файл — один пакет.
- Параллельно не больше трёх субагентов; тяжёлые гейты (полные тесты, сборка) — только
  координатором между волнами, не субагентами.
- Каждая задача — отдельный коммит после приёмки координатором; откат одного пакета
  не задевает соседние.
- Если субагент вернул спорное решение по глоссарию — координатор фиксирует термин и
  обновляет глоссарий до следующей задачи.

## 9. Риски

- **Машинный перевод комментариев теряет смысл.** Лечится требованием переводить по смыслу,
  запретом сокращать и добавлять пояснения, выборочной вычиткой координатором.
- **Пропущенные строки.** Лечится сканером и разноской по волнам, а не вычиткой.
- **Субагент меняет поведение.** Лечится контрактом, проверкой `git diff` и полным прогоном
  тестов в конце волны.
- **Конфликты при будущем слиянии с upstream.** Неизбежны; смягчаются коммитами по пакетам.
- **Маршрут opencode-go недоступен.** Блокер волны 0, требует решения владельца.

## 10. Оценка

Волна 0 — часы. Волна 1 — основная смысловая работа, 3–5 дней исполнителя.
Волна 2 — объёмная механическая, 3–4 дня. Волны 3–4 — 3–5 дней. Волна 6 — 1–2 дня.
